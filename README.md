# Wingo Signal Pro - AI Trading VIP

Premium AI-powered trading signal analysis platform with real-time charting and prediction capabilities.

## Features

- **Time Options**: Choose between 5s, 30s, and 1m trading intervals
- **All Currencies & OTC**: Major pairs, OTC pairs, and crypto support
- **Predict Button Pro**: One-tap AI signal generation with animated UI
- **AI Live Server Analysis**: Real-time Buy/Sell signal generation with confidence scoring
- **Ultra Animations**: Particle background, glass morphism, gradient effects, live chart
- **Predict History**: Full signal history with stats tracking and clear functionality
- **AI Trading Wallpaper**: Cyberpunk-inspired dark UI with animated particle network

## Getting Started

Open `index.html` in any modern browser, or deploy via GitHub Pages.

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES5+)
- Canvas-based live chart and particle animations
- Glass morphism UI with CSS animations
- Fully responsive design
- Zero dependencies - no frameworks required
