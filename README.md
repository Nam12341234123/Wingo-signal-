# Wingo Predict AI Tool

**Real AI Analysis System v3.0 Ultra**

An advanced AI-powered chart analysis tool that predicts outcomes using real image processing and pattern recognition.

## Features

- **Chart Screenshot Input** — Upload or drag-and-drop chart screenshots for analysis
- **AI Server Prediction** — Real-time image analysis using pixel-level pattern recognition
  - **Big/Small** prediction with probability bars
  - **Number** prediction (0-9) with animated wheel display
  - **Colour** prediction (Red/Green/Violet) with glowing orb visualization
- **Pattern Analysis** — Detects trends, volatility, cyclic patterns with interactive chart
- **Prediction History** — Track all past predictions in a scrollable log
- **Ultra UI** — Dark glass-morphism design with neon accents, animated particles, and smooth transitions

## How It Works

1. Upload a chart screenshot (PNG, JPG, JPEG, WEBP)
2. Click **ANALYZE WITH AI**
3. The AI engine processes the image through multiple phases:
   - Color distribution analysis
   - Pattern detection (ascending/descending waves, volatility, cycles)
   - Trend analysis (bullish/bearish momentum)
   - Shannon entropy calculation
4. View predictions for Big/Small, Number, and Colour with confidence scores

## Tech Stack

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Canvas API for image analysis and chart rendering
- CSS Glass-morphism + Grid/Flexbox layout
- GPU-accelerated CSS animations
- Google Fonts (Orbitron, Rajdhani, Inter)

## Quick Start

Open `index.html` in any modern browser — no build step required.
